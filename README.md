# felicidade-idade-pais
 Análise de Indicadores de Felicidade por Idade e País

Projeto de análise exploratória e modelagem sobre a relação entre faixas etárias, fatores socioeconômicos e o índice de felicidade global.

## 👥 Integrantes da Dupla
* Sofia Miyuki Moriya de Farias
* Priscilla de Souza Jardim

## 📖 Contexto e Objetivos
Analisar como a percepção de bem-estar (escala Cantril Ladder) varia entre faixas etárias e verificar a correlação com indicadores do Banco Mundial (PIB per capita, população e área territorial).
